# Exploratory Data Analysis (EDA) & Business Intelligence Project

## 📌 Overview
This project is part of Task-2 of the Data Analytics Internship at ApexPlanet Software Pvt Ltd.

The objective of this project is to perform **Exploratory Data Analysis (EDA)** on a retail dataset to uncover patterns, trends, and business insights using Python.

---

## 📊 Dataset Information

The dataset contains retail order data with 9994 rows and 16 columns.

### Columns:
- Order Id
- Order Date
- Ship Mode
- Segment
- Country
- City
- State
- Postal Code
- Region
- Category
- Sub Category
- Product Id
- Cost Price
- List Price
- Quantity
- Discount Percent

---

## 🎯 Objectives

- Perform descriptive statistical analysis
- Analyze trends and patterns in data
- Generate business insights
- Create visualizations
- Build a structured output for reporting

## 🔍 Data Analysis Steps

1. Data loading and inspection
2. Data cleaning (handled in Task-1)
3. Descriptive statistics generation
4. Grouping and aggregation (similar to SQL)
5. Data visualization (charts and graphs)
6. Correlation analysis
7. Exporting results as CSV and images

---

---

## 📈 Key Insights

- 📊 **Category Performance:**
  - Technology category generates the highest sales.
  - Office Supplies and Furniture follow behind.

- 🌍 **Regional Performance:**
  - West region contributes the highest revenue.
  - Central region has comparatively lower sales.

- 📅 **Sales Trends:**
  - Sales show fluctuations across months.
  - Certain months experience peak sales indicating seasonal demand.

- 🛒 **Top Products:**
  - A few sub-categories dominate total revenue.
  - High-performing products significantly impact total sales.

- 🔗 **Correlation Analysis:**
  - Strong positive relationship between **Quantity and Total Sales**.
  - Price and discount influence overall revenue patterns.

## 📌 Conclusion

This project demonstrates how raw retail data can be transformed into meaningful insights using Python.

Key learnings:
- Data cleaning is essential before analysis
- Aggregation techniques help answer business questions
- Visualization makes patterns easy to understand
- EDA is a critical step before building dashboards or ML models

The insights generated can help businesses:
- Improve sales strategies
- Focus on high-performing regions and products
- Understand customer demand patterns
